# Security / 安全

## Reporting / 报告问题

Please report vulnerabilities privately to the repository owner. Do not include tokens, conversation content, private repository data, or authentication files in a public issue.

请私下向仓库所有者报告安全漏洞。请勿在公开 Issue 中包含令牌、对话内容、私有仓库数据或认证文件。

## Boundaries / 安全边界

The suite binds to loopback only, stores data locally, rejects credential-like configuration keys, and does not package Codex authentication data.

套件仅绑定 loopback 地址、在本机存储数据、拒绝疑似凭据配置项，并且不会打包 Codex 认证数据。
