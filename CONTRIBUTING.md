# Contributing / 参与贡献

Use Node.js 22 or newer. Run `npm install`, `npm test`, and `npm run check:release` before opening a pull request. Keep all code comments in English and add matching `en` and `zh-CN` entries for every user-visible string.

请使用 Node.js 22 或更高版本。提交 Pull Request 前运行 `npm install`、`npm test` 与 `npm run check:release`。所有代码注释必须使用英文，每项用户可见文本必须同时提供 `en` 和 `zh-CN` 翻译。
